FM-1
SAMPLE LAB

M-VAVE FM-1（SLOOP 2.8.5）で演奏した音を iPhone で録音し、エフェクターで加工して、ユーザードラムキットの16パッドに配置し、FM-1形式WAVで書き出す作業アプリです。書き出したWAVは SLOOP公式エディタから選んだUSRスロットへ送ります。USB-C で FM-1 をつないだ状態で使ってください。

01　録音 — FM-1の音を取り込む

FM-1側は HOME → USB AUDIO を FULL、USB RATE は 48kHz 推奨。ヘッドホン端子にプラグを挿すと内蔵スピーカーがミュートできます。録音許可を押すと、iPhoneにつながった FM-1（Felucca）が入力として使われます。

02　加工 — エフェクターラック

使いたいエフェクトを ON にしてツマミを調整。「FXプレビュー」で加工後の音を確認し、「加工を確定」で下の波形にレンダリングします。プリセットから始めるのが早いです。

10 EFFECTS
加工後サンプル：まだ確定していません（プレビューだけでも試聴できます）
FM-1のサンプル仕様に合わせ、FM-1用WAVは 22kHz / モノ / 16bit で書き出します。1スロット約7.4秒が上限の目安です。長すぎる音はトリムで短くしてください。

03　ドラムキット — 好きな場所に入れる

送り先スロットと16パッドを組み立てます。パッドを選んで「確定したサンプルをこのパッドへ」を押すだけ。パッドをタップすると試聴できます。

USR1–4 / 16 PADS

PAD 1 — 空

サンプルが入っていません。先に 01 で録音し、02 で加工を確定してください。

04　書き出しと転送 — SLOOPエディタ経由でFM-1へ

パッドWAVの書き出しはこのページで完結します。FM-1本体への転送（SysEx）は SLOOP公式エディタの Drum kit ページから行います。下の手順どおりに、MIDIWeb ブラウザでエディタを開いて送ってください。Web MIDI が使える環境では、このページから FM-1 に接続してパッド音（ドラムch）を鳴らして確認もできます。

WAV EXPORT + EDITOR
MIDIログ：—　※ Safari / 通常のChromeでは Web MIDI が使えません。MIDIWeb ブラウザで開いてください。
  • 1上の「全部WAV保存」で、パッドごとのWAVを iPhone の「ファイル」に保存する（名前が pad01〜pad16 になります）。
  • 2FM-1をUSB-Cで先につないだ状態で、MIDIWeb ブラウザで SLOOP Webエディタ を開き、Connect を押して MIDI と SysEx を許可する。送る前にエディタの Backup でバックアップを取る。
  • 3エディタの Drum kit ページで、送り先にこのページで選んだスロット（おすすめは USR3+4）を選び、各パッドにWAVを「Choose files」から割り当てる。iPhoneではドラッグ＆ドロップは使えません。
  • 4Send で FM-1 へ送信する。SysExは量が多いので、最初は音数の少ないキットで試すのが安全です。
  • 5FM-1側で ドラムトラック（Track 4）→ KIT を USR3+4（キット42）／選んだUSRに合わせて、パッド（白鍵）を叩いて鳴るか確認する。
転送前の注意：USRスロットの中身は送信で上書きされます。送る前に SLOOPエディタの Backup で現在のキットを保存し、最初は音数の少ないキットで試してください。
