## SUPER ESELATORとは

SUPER ESELATORは、ブラウザ上で演奏・ループ録音・音色選択・エフェクト操作・WAV書き出しまで行える、16-bitゲーム機風のライブ・パフォーマンス・インストゥルメントです。

タッチパッド、コードパッド、4つの独立DECKを使い、ビート、ベース、コード、環境音を重ねながら直感的にトラックを組み立てられます。

---

## 4-DECK PERFORMANCE SYSTEM

4つのDECKに、それぞれ別の音色を割り当て可能です。

- DECKごとに独立した音色設定
- DECKごとのMUTE操作
- 演奏中でもDECK切替・MUTE操作が可能
- ベース、コード、ピアノ、ドラム、環境音などを同時にレイヤー可能
- CLEAR機能で、選択中DECKの演奏データだけを消去可能

例えば、

```text
DECK A: Bass
DECK B: Lead / Melody
DECK C: Piano / Chord
DECK D: Drum Kit / Ambient
```

のように役割分担できます。

---

## TOUCH PAD PERFORMANCE

メインのタッチパッドは、横方向で音階、縦方向でフィルターを操作します。

- 横8マスのスケール演奏パッド
- グリッド線と音名表示で音程を視覚的に確認
- KEYとSCALEに追従した安全な音階演奏
- タッチパッドのY軸でローパスフィルターを操作
- 上側は明るく開いた音、下側は強くこもった音
- マルチタッチに対応し、複数の音を同時に鳴らすことが可能

音階はMajor、Minor、Pentatonic、Blues、Dorian、Japanese Insen、Hirajoshiなど、多数のスケール／モードから選択できます。

---

## OCTAVE SHIFT

タッチパッド下部のオクターブコントロールにより、演奏音域を変更できます。

```text
◀  OCT: -3 ～ +3  ▶
```

- タッチパッドの演奏音域を上下に移動
- コードパッドも同時にオクターブ移動
- 低域のベース演奏から高域のメロディ演奏まで対応
- 8マスの操作性を保ったまま音域だけを切替可能

---

## CHORD PAD

タッチパッド下の5つのコードパッドは、選択中のKEYとSCALEから自動的にコードを生成します。

- KEY変更に追従
- SCALE変更に追従
- オクターブ変更に追従
- コード名を自動表示
- コード演奏もループ録音可能

メロディを弾きながら、コードパッドで即座に和音を重ねられます。

---

---

## LIVE LOOP RECORDING

演奏したノートはリアルタイムでループ録音できます。

- RECで録音待機
- 最初の演奏から録音開始
- 録音停止時にループ長とBPMを自動計算
- 再生中のオーバーダブ録音
- UNDOで直前の録音状態へ戻る
- X2 DUPでループシーケンスを2倍へ拡張
- DECK単位で録音データをCLEAR可能

短いビートループから、複数DECKを重ねたライブ構成まで作成できます。

---

## MASTER EFFECTOR ENGINE

マスターエフェクトは、音全体に対してリアルタイムに適用されます。

- Hall Reverb
- Echo Delay
- Lowpass Filter
- Delay + Filter

XY PAD、スライダー、モーダル画面からパラメーターを操作できます。

```text
X AXIS: Effect parameter 1
Y AXIS: Effect parameter 2
```

残響の長さ、ディレイのフィードバック、フィルターのカットオフやレゾナンスなどを、演奏中に変化させられます。

- FX ON / OFF

作業途中のセッションを残したり、ライブ用セットを複数準備したりできます。

## WAV EXPORT

- WAV形式でダウンロード
- ブラウザだけで簡易デモや素材を制作可能

## What is SUPER ESELATOR?

SUPER ESELATOR is a browser-based live performance instrument inspired by 16-bit game consoles. It lets you play sounds, record loops, switch presets, control effects, save projects, and export WAV files—all in one interface.

Using the touch pad, chord pads, and four independent decks, you can build layered tracks with beats, basslines, chords, melodies, and ambient sounds in real time.

---

## 4-DECK PERFORMANCE SYSTEM

SUPER ESELATOR features four independent decks, each with its own sound preset.

- Assign different sounds to Deck A–D
- Mute each deck independently
- Switch decks and mute channels during performance
- Layer bass, chords, piano, drums, and ambient sounds
- Clear recorded data from the selected deck only

Example setup:

```text
DECK A: Bass
DECK B: Lead / Melody
DECK C: Piano / Chords
DECK D: Drum Kit / Ambient
```

---

## TOUCH PAD PERFORMANCE

The main touch pad controls pitch horizontally and filtering vertically.

- 8-step scale performance pad
- Grid lines and note labels for visual guidance
- Safe scale-based playing based on the selected Key and Scale
- Y-axis controls the low-pass filter
- Higher positions create a brighter, more open sound
- Lower positions create a darker, heavily filtered sound
- Multi-touch support for playing multiple notes at once

Available scales include Major, Minor, Pentatonic, Blues, Dorian, Japanese Insen, Hirajoshi, and more.

---

## OCTAVE SHIFT

The octave control at the bottom of the touch pad changes the playable range.

```text
◀  OCT: -3 to +3  ▶
```

- Shift the touch pad range up or down
- Chord pads follow the same octave shift
- Play deep basslines or high melodies
- Keep the same easy-to-play 8-step layout while changing register

---

## CHORD PAD

The five chord pads below the touch pad automatically generate chords based on the selected Key and Scale.

- Follows Key changes
- Follows Scale changes
- Follows Octave changes
- Automatically displays chord names
- Chord performances can also be loop recorded

You can play melodies on the touch pad while instantly layering harmonic chords.

## LIVE LOOP RECORDING

Performed notes can be recorded into loops in real time.

- Arm recording with REC
- Recording begins with the first note played
- Loop length and BPM are calculated automatically
- Overdub while the loop is playing
- Use UNDO to return to the previous recording state
- Use X2 DUP to double the sequence length
- Clear recorded notes by deck

From short beat loops to layered multi-deck live arrangements, you can build a full performance on the fly.

---

## MASTER EFFECTOR ENGINE

Master effects are applied to the full audio output in real time.

- Hall Reverb
- Echo Delay
- Lowpass Filter
- Delay + Filter

Effects can be controlled from sliders or the XY Pad modal.

```text
X AXIS: Effect Parameter 1
Y AXIS: Effect Parameter 2
```

Adjust reverb decay, delay feedback, delay time, filter cutoff, and resonance while performing.

---

## PROJECT SAVE / LOAD

Sessions can be saved and loaded as JSON project files.

Saved data includes:

- Key and Scale
- Sound presets for each deck
- Mute states for each deck
- FX on/off state
- FX type and parameters
- Loop length and BPM
- Recorded note data
- Drum kit assignments such as Kick, Snare, and Hi-Hat

This makes it easy to save unfinished sessions or prepare multiple live-performance sets.

---

## WAV EXPORT

The built-in WAV recorder lets you export your performance as an audio file.

- Records the master output
- Includes live playing, loops, and effects
- Downloads as a WAV file
- Create demos, sketches, and sound materials directly in the browser

---

## KEYBOARD PERFORMANCE

SUPER ESELATOR can also be performed using a computer keyboard.

- Play the 8-note scale pad
- Select decks
- Mute decks
- Record, undo, and clear loops
- Start and stop playback
- Change sound presets
- Toggle FX on and off
- Shift octaves

By combining touch controls and keyboard controls, SUPER ESELATOR supports a flexible live performance workflow.
